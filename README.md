# Folio

A desktop PDF reader and editor for Windows. Read, edit text, sign, annotate, fill forms, redact, run OCR and manage pages. Everything works offline.

## Install
1. Download `Folio Setup <version>.exe` from the Releases page.
2. Run it. Windows will show **"Windows protected your PC"** and name the publisher as unknown. Folio is not code-signed yet, so this is expected.
3. Click **More info**, then **Run anyway**.

## Build from source
```
npm install
npm start
npm run dist
```
